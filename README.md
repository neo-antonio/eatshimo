# eatshimo

Eatshimo is a lightweight, privacy-focused, and free open-source calorie and fitness tracker built as a Progressive Web App (PWA). It works entirely on your device with no ads, subscriptions, accounts, or tracking.

The goal of Eatshimo is simple: provide a straightforward calorie tracking experience without the clutter, paywalls, and inaccurate community databases commonly found in other fitness apps.

## Features

* Record meals with grams, calories, macros, and fiber
* Auto adjust values based on grams or set manually without affecting food library
* Record daily water, steps, weight, and sleep
* Record daily, weekly, monthly, or custom exercises and habits
* Fasting timer with customizable hours and duration
* Food moderator helps you tag food and creates a cooldown duration before you can eat the food again
* Get suggested calories, set targets, and adjust timezone in settings in your profile
* See simple statistics from daily, weekly, monthly, or custom dates
* Export, import, or delete all local data with ease

## Installation and Usage Guide

### Use the Hosted Version

The easiest way to use Eatshimo is through the hosted web version.

Open the application in your preferred browser and start tracking immediately. All data is stored locally on your device and is never sent to any server.

### Install on Android

To install Eatshimo as a PWA on Android:

1. Open Eatshimo in Chrome or Brave.
2. Tap the browser menu.
3. Select **Install App** or **Add to Home Screen**.
4. Confirm the installation.

### Install on iPhone and iPad

To install Eatshimo on iOS:

1. Open Eatshimo in Safari.
2. Tap the **Share** button.
3. Select **Add to Home Screen**.
4. Tap **Add**.

### Install on Desktop

To install Eatshimo on Windows, macOS, or Linux:

1. Open Eatshimo in Chrome, Edge, or Brave.
2. Click the install icon in the address bar.
3. Confirm installation.

### Run Locally

If you prefer running Eatshimo locally:

1. Download the latest release ZIP file.
2. Extract the contents.
3. Open `index.html` in any modern browser.

No build process or additional dependencies are required.

## Updating

### Hosted Version

The hosted version automatically receives updates whenever a new version is released.

### Local Version

If you are using the downloaded ZIP version, you will need to manually download future releases to receive updates.

## Data Privacy

Eatshimo uses a local-first approach.

* No user accounts
* No analytics
* No tracking
* No cloud storage
* No personal data collection

All information remains stored locally on your device.
